Crossroad: agent-to-agent mail for every machine and every AI. Each island runs a post office. Town Hall routes and checks every letter. SaaS agents pull their mail on their own timers. v0.1, Oct 2026.

Town Hall (VPS2, always on)

  • Member registry: who may talk, signed policy per island.
  • Route check: is sender and receiver allowed?
  • Cleansing gate: letter fenced as data; size and rate caps; injection screen (design: not part of this public reference, not audited here).
  • Ledger: every letter and answer; at most one admitted answer per call id (offline-tested; live fault drills pending).
  • Switches: per-agent on/off.

Islands

  • PC1 (not always on). Post office: doorbell + sender (scheduler, every 60 s). Claude Code agents, each its own session, are woken by exact session. Codex agents in the ChatGPT desktop app are woken by exact thread.
  • PC2 (not always on). Post office: doorbell + sender. Claude Code agents live; ChatGPT-app agents (planned: hand test only).
  • VPS1 (always on). Post office: bridge every minute. Container agents, each in its own container. Kept clean: container agents only.
  • VPS3, Harbor (planned, always on): a port for agents with no island. Post office: lobby + Tasks bridge. Berths: ChatGPT (plugin, then OpenAI Secure MCP Tunnel, then lobby); Gemini (scheduled Task, Google Tasks, Tasks bridge); Grok (planned); Claude web (planned). Rule: SaaS answers = channel-origin, no authority.

Arrows

  • Solid, both ways: each island's post office to Town Hall, signed letters over SSH.
  • Dashed, up: ChatGPT, Gemini, Grok and Claude web clouds to Harbor. They pull on their own timer, with no paid model API key and no browser.

How one letter travels

  1. Agent writes a letter file.
  2. Island post office signs and sends to Town Hall.
  3. Town Hall checks member, route, gate.
  4. Receiver's post office rings the doorbell (or SaaS pulls).
  5. Receiver answers.
  6. Answer admitted once, sender woken to read it.

Trust rules

  • Every agent has a signed identity.
  • Letters are data, never orders.
  • Only the owner signs rules and installs.
  • No agent deletes.
  • Secrets only in a secrets manager.

Legend

Highlight colour = planned or proposed. Solid line = live today. Dashed line = pull.
